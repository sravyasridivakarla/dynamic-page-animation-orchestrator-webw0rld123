# CLAUDE.md Template

Create `CLAUDE.md` at repo root after implementing all code.

## Required Sections
1. **Project Overview** — name, tech stack, description
2. **API Endpoint Reference** — table with Method, Path, Description, Request Body, Response
3. **Data Models** — all models with fields, types, relationships
4. **Environment Variables** — all required vars with descriptions
5. **Running the Service** — dev and production commands
6. **Database** — type, connection, migration commands, schema overview

Include every endpoint, every field, every model. No abbreviations.
